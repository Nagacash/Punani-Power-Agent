# Project Default Routes

# --- Design & UI
when: the user wants design polish and visual improvements -> impeccable
when: the user needs writing that sounds natural, not AI-generated -> humanizer
when: the user needs diagrams, charts, or schemas -> diagram-design
when: the user is building a visual design system -> power-design

# --- Web & Scraping
when: the user is scraping a site that says no -> scrapling-official
when: the user wants to drive a real browser -> browser-use
when: the user needs to interact with a web page -> browser-testing-with-devtools

# --- Video & Media
when: the user is working with hyperframes video -> hyperframes
when: the user needs to generate or edit video -> remotion-best-practices
when: the user needs diagrams or flowcharts -> diagram-design

# --- Code & Development
when: the user wants code structure analysis -> code-structure
when: a change needs a PR, changelog or release note -> document
when: new behaviour needs new tests written for it -> test
when: the same operational logic is duplicated -> code-structure

# --- Naga Codex workflow
when: the user says refactor, clean this up, or that the same logic is duplicated -> refactor-safely
when: a UI change needs before and after images -> before-and-after
when: human-facing text has to lose its AI tells -> unslop
when: the user asks whether the UI looks right -> ui-audit
